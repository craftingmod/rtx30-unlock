# RTX-UNLOCK

This folder contains the files used by RTX-UNLOCK.

## Firmware assets

The `ASSETS/` folder should contain the files downloaded by `bun run firmware:assets`.

## Debug logging

Create an empty `DEBUG.ON` file in the RTX-UNLOCK folder to enable logging.
When debug mode is enabled, `RUNxx` and `PROBExx` log files are created in this folder.
